# Stratum

Local-first AI-assisted engineering runtime workstation.

This repository currently contains only the bootstrap skeleton. Runtime code, dependencies, API services, desktop shell code, tools, and agent execution are intentionally not included in this step.

## Structure

- `backend/` - future backend runtime area
- `desktop/` - future desktop UI area
- `docs/` - architecture, context, and engineering specifications
- `scripts/` - future project scripts
- `workspace/` - local working area
- `logs/` - runtime logs
- `artifacts/` - generated task artifacts
