# Stratum

Local-first AI-assisted engineering runtime workstation.

The backend now includes the v0.6.0 runtime query observability and
reconstruction layer: runtime queries, projection lifecycle/replay/drift,
governance audit, decision and artifact lineage, runtime reconstruction views,
operational analytics, and runtime intelligence summaries.

v1.0 execution now lives in `docs/roadmap/STRATUM_V1_0_EPIC_ROADMAP.md`, with
future Codex prompt guidance in `docs/prompts/CODEX_WORKFLOW_NOTE.md`.

## Structure

- `backend/` - FastAPI backend runtime and query observability services
- `desktop/` - future desktop UI area
- `docs/` - architecture, context, and engineering specifications
- `scripts/` - future project scripts
- `workspace/` - local working area
- `logs/` - runtime logs
- `artifacts/` - generated task artifacts
