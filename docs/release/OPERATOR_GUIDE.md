# Operator Guide

## Daily Flow

1. Open the desktop console.
2. Connect to the local backend.
3. Open or attach a repository.
4. Attach engineering specifications.
5. Create or inspect a task.
6. Review the generated plan and approvals.
7. Execute governed work.
8. Inspect timeline, artifacts, and evaluation results.
9. Replay the session if needed.
10. Shutdown cleanly.

## Operating Principles

- Approvals gate risky actions.
- The timeline is the audit record.
- Artifacts and patches are lineage-tracked.
- Replay is the verification mechanism for historical reconstruction.

## Manual Validation

The release candidate should be validated with one complete operator workflow
covering repository, workspace, task, planning, provider execution, approvals,
artifacts, evaluation, summary, replay, and shutdown.
