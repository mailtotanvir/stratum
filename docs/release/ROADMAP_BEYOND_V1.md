# Roadmap Beyond v1

## Explicitly Deferred

- Cloud deployment
- Multi-user collaboration
- New provider families
- New agent frameworks
- New execution protocols in the core kernel
- Rich distributed telemetry pipelines
- Non-local workspace synchronization

## Future Direction

Stratum beyond v1 should extend through adapters, not through core lock-in.
The core runtime should remain deterministic, event-first, and reconstructable.
